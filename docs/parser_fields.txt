# Поля парсера 1С + Б24 NEW

## Активные источники

Парсер поддерживает два входных файла:

1. 1С, лист `TDSheet`, 45 позиционных колонок.
2. Б24 NEW, лист `Отчет по сделкам`, сопоставление по заголовкам.

Старый Универсальный отчёт используется только как эталон формул.

## Межсистемные равенства

| Бизнес-поле | 1С | Б24 NEW |
| --- | --- | --- |
| Кейс/лид | цифровой блок из `Кейс`, без ведущих нулей | `Лид` |
| Сделка/заказ | номер из строки `Заказ` | `ID` |
| Тип клиента | `Подразделение` | `Тип клиента` |
| Дата услуги | `Дата реализация` | `Дата оказания услуги` |

Пример номера кейса:

```text
Кейс 00000210242 от 10.07.2026 11:30:41
→ case_id = lead_id = 210242
```

Удаляются только ведущие нули, а не нули внутри номера.

## Туристическая аналитика

| Поле | 1С сейчас | Б24 NEW |
| --- | --- | --- |
| `country` | отсутствует | Страна |
| `city` | отсутствует | Город |
| `hotel` | отсутствует | Отель |
| `start_date` | отсутствует | Дата начала |
| `end_date` | отсутствует | Дата окончания |
| `nights_count` | отсутствует | Количество ночей |
| `rooms_count` | отсутствует | Количество номеров |

Эти поля рекомендуется добавить в выгрузку 1С. Парсер уже поддерживает их через `extra_by_header`.

## Расчётные поля

```text
sales_amount
profit
profit_ex_vat
sales_amount_after_refund
profit_after_refund
profit_after_refund_ex_vat
supplier_retained
vat_factor
date_for_sales
date_fallback_used
is_refund

```

Формулы хранятся в `mapping.json`. `NZ(value)` заменяет пустое значение на ноль только внутри формулы.

## Поля, которых не хватает в выгрузках

### Б24 NEW

| Приоритет | Поле | Зачем |
| --- | --- | --- |
| P0 | Дата оплаты клиентом | Финансовый период Б24 |
| P1 | Номер заказа/сделки 1С | Контроль связи с 1С |
| P1 | Дата последней активности | SLA и зависшие сделки |
| P1 | Плановая дата закрытия | Прогноз и просрочка |
| P1 | Дата изменения сделки | Свежесть и инкрементальная загрузка |
| P2 | Количество звонков/встреч | Активность команды |
| P2 | Дата возврата/отмены | Временная аналитика возвратов |
| P2 | Ставка и режим НДС | Операции 0%, без НДС и специальные схемы |

Пока `Дата оплаты клиентом` пуста, сделка загружается в воронку, но не получает `date_for_sales` и не включается в финансовую динамику выбранного периода.

### 1С

| Приоритет | Поле | Зачем |
| --- | --- | --- |
| P1 | Явный номер кейса/лида | Исключить regex длинной строки |
| P1 | Явный номер сделки/заказа | Исключить regex длинной строки |
| P1 | Уникальный ID операции | Контроль повторной загрузки |
| P1 | Тип операции и ID исходной операции | Различать продажу, возврат, корректировку |
| P2 | Дата возврата/отмены | Временная аналитика |
| P2 | Валюта, курс, сумма в валюте | Валютная сверка |
| P2 | Название сделки/тема кейса | Детализация без несуществующего индекса |
| P1 | Страна, город, отель | Туристические срезы по обоим источникам |
| P1 | Дата начала/окончания, ночи, номера | Период и объём гостиничной услуги |

`Тип клиента` отдельно добавлять не обязательно: по принятому правилу им является `Подразделение`.
`Тип запроса` необходимо добавить с точным заголовком `Тип запроса`.
