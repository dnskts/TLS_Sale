# Сводный отчёт

## 1. Назначение

`Сводный.xlsx` — рабочая книга финансового аналитика, которая вручную объединяет сведения о заказах из 1С и сведения о кейсах/сделках из Битрикс24. Книга используется для анализа:

- продаж и прибыли по агентам и командам;
- количества обращений и стадий воронки;
- клиентской статистики;
- категорий услуг;
- продаж и прибыли после возвратов.

Книга не является полностью автономной: часть вычисляемых полей листа кейсов зависит от внешних файлов-справочников, а часть итогов хранится в кэшах сводных таблиц.

## 2. Структура книги

| Лист | Диапазон | Назначение | Особенности |
| --- | --- | --- | --- |
| `Свод продажи` | `A1:O50` | Продажи по командам и агентам в разрезе месяцев | 1 сводная таблица |
| `Свод прибыль` | `A1:O50` | Прибыль без НДС после возвратов | 1 сводная таблица |
| `Cвод обращения` | `A1:AO65` | Количество и доли обращений по воронке и статусам | 6 сводных таблиц |
| `Cвод обращения с ФИО` | `A1:L435` | Обращения с детализацией до агента | 1 сводная таблица |
| `Статистика по Клиенту` | `A1:P19` | Количество заказов, продажи и прибыль по клиенту/категории | 2 сводные таблицы и 34 формулы |
| `Кейс дв13.07.26(01.01-13.07)` | `A1:AB1079` | Детальные данные кейсов Б24 | 1 076 записей, 5 458 формул |

В книге нет объединённых ячеек и структурированных Excel-таблиц (`ListObject`).

## 3. Вкладка `Свод продажи`

### 3.1. Что выведено

Сводная показывает сумму поля `Сумма продажи после возврата`:

- строки: `Команда` → `Агент new`;
- столбцы: год → месяц даты операции;
- значение: сумма продаж после возвратов;
- фильтры: дата реализации, поставщик, `категория NEW`;
- рабочая область: `A6:O50`.

Итог отражает фактическую сумму продаж за вычетом возврата клиенту. Для новой выгрузки Б24 показатель восстанавливается как:

```text
Сумма продажи после возврата =
    Всего к оплате Клиентом
    - Сумма возврата клиенту
```

Для строки Excel новой выгрузки:

```excel
=BD2-BF2
```

### 3.2. Ограничение источника

Сводная ссылается на кэш, содержащий 14 046 записей заказов, хотя видимый лист заказов содержит только 1 891 строку данных. Исторические значения из кэша нельзя полностью восстановить по текущему детальному листу.

## 4. Вкладка `Свод прибыль`

### 4.1. Что выведено

Структура аналогична вкладке продаж:

- строки: `Команда` → `Агент new`;
- столбцы: год → месяц;
- значение: сумма `Прибыль РС ТЛС с учетом возврата без НДС`;
- фильтры: дата реализации, поставщик, `категория NEW`;
- рабочая область: `A6:O50`.

### 4.2. Финансовая логика для Б24 NEW

Базовая прибыль:

```text
Прибыль =
    Дополнительная выгода
    + Сервисный сбор
    + Комиссия
```

```excel
=AT2+AX2+AZ2
```

Прибыль без НДС:

```text
Прибыль без НДС =
    Дополнительная выгода
    + (Сервисный сбор + Комиссия) / 1,22
```

```excel
=AT2+(AX2+AZ2)/1.22
```

Прибыль с учётом возврата:

```text
Прибыль после возврата =
    Дополнительная выгода
    + Сервисный сбор
    + Комиссия
    - Возврат дополнительной выгоды
    - Возврат сервисного сбора
    - Возврат комиссии
    + Сбор РС ТЛС за возврат
    + Штраф РС ТЛС за возврат
```

```excel
=AT2+AX2+AZ2-BO2-BM2-BI2+BU2+BW2
```

Прибыль после возврата без НДС:

```excel
=(AT2-BO2)+(AX2-BM2+AZ2-BI2+BU2+BW2)/1.22
```

Здесь дополнительная выгода не делится на 1,22; НДС выделяется из комиссии, сервисного сбора, сбора и штрафа РС ТЛС.

## 5. Вкладка `Cвод обращения`

### 5.1. Общая структура

На вкладке находятся шесть сводных таблиц:

| Область | Содержание |
| --- | --- |
| `A5:H30` | Количество всех кейсов |
| `A39:H64` | Доля каждого значения от итога столбца |
| `S5:Z30` | Количество кейсов без бесплатных категорий |
| `S39:Z64` | Доли без бесплатных категорий |
| `AH5:AO28` | Гостиничные категории с дополнительными исключениями |
| `AH39:AO62` | Доли для гостиничного блока |

Во всех блоках:

- строки: `Воронка` → `Статус сделки`;
- столбцы: год → месяц даты создания;
- значение: количество `Номер сделки`;
- фильтры: категория и ответственное лицо/агент.

### 5.2. Фильтры

- В общих блоках исключена категория `Консультация по картам МБ`.
- В блоках «без бесплатных заказов» скрыто 12–13 категорий, не формирующих оплачиваемую услугу.
- Гостиничный блок оставляет категории `Отель` и `Accommodation Hotels TR`.
- В части блоков исключены отдельные агенты и Corporate-направление.

### 5.3. Интерпретация

Количество обращений нельзя считать по финансовым строкам 1С: одна сделка Б24 может соответствовать нескольким строкам услуг или оплат. Единица показателя здесь — уникальная сделка/кейс Б24.

## 6. Вкладка `Cвод обращения с ФИО`

Сводная детализирует обращения:

- строки: `Команда` → `Агент` → `Воронка` → `Статус`;
- столбцы: год → месяц создания;
- значение: количество сделок;
- фильтр: категория;
- рабочая область: `A3:L435`.

Вкладка используется для анализа личной нагрузки и результатов агентов внутри команд.

## 7. Вкладка `Статистика по Клиенту`

### 7.1. Первая сводная

Область `A4:C9`:

- строки: категория → подкатегория;
- фильтры: клиент и ID клиента;
- значение: количество сделок.

### 7.2. Вторая сводная

Область `E3:H6`:

- строки: `категория NEW`;
- фильтр: клиент;
- показатели: уникальное количество заказов, сумма продажи, прибыль без НДС;
- источник: модель данных Power Pivot, а не обычный диапазон листа.

### 7.3. Формулы шаблона

```excel
O4:O18 =IFERROR(M4/L4,0)
P4:P18 =IFERROR(N4/M4,0)

K19 =SUM(K4:K18)
L19 =SUM(L4:L18)
M19 =SUM(M4:M18)
N19 =SUM(N4:N18)
```

Формулы рассчитывают отношения показателей и итоговые суммы. В текущем кэше значительная часть шаблонных значений равна нулю.

## 8. Вкладка кейсов

### 8.1. Гранулярность и состав

- строки 2–3: технические и нормализованные заголовки;
- строки 4–1079: 1 076 кейсов;
- строки 4–600: 597 записей первого блока;
- строки 601–1079: 479 записей из нового Б24;
- все 479 ID второго блока найдены в `Б24 NEW.xlsx`.

Сводный кэш обращений содержит 9 174 кейса, поэтому видимый лист является только частью исторического источника.

### 8.2. Основные вычисляемые поля

Нормализация статуса:

```excel
W4:W1079 =VLOOKUP(S4,'[1]Cправочник статусов'!A:B,2,0)
```

Нормализация имени агента и команды:

```excel
X4:X600 =VLOOKUP(R4,'[1]Справочник агентов 06.26'!A:B,2,0)
X601:X1079 =R601
Y4:Y1079 =VLOOKUP(X4,'[1]Справочник агентов 06.26'!B:F,5,0)
```

Классификация категории и номера группы для нового блока:

```excel
AA601:AA1079 =VLOOKUP(I601,'[2]Справочник для обращений'!D:G,4,0)
AB601:AB1079 =VLOOKUP(AA601,'[2]Справочник для обращений'!J:K,2,0)
```

Для первого блока встречаются варианты:

```excel
=VLOOKUP(I4,'[1]Справочник для обращений'!A:E,5,0)
=VLOOKUP(Z4,'[1]Справочник для обращений'!C:G,5,0)
```

Для части записей формируется составной ключ:

```excel
Z4 =CONCATENATE(I4,"/",K4)
```

### 8.3. Внешние зависимости

- ссылка `[1]` ведёт на файл из локального Outlook-cache от 13.07.2026;
- ссылка `[2]` ведёт на сетевой файл `06.07.26 воронка продаж.xlsx`.

Без этих справочников пересчёт формул может вернуть `#REF!` или `#N/A`. Для автоматизации справочники статусов, агентов, команд и категорий должны храниться отдельно от рабочей книги и загружаться парсером явно.

Одна строка не всегда равна одному счёту. В 1С один счёт может быть разбит на несколько услуг и финансовых операций.

## 10. Справочник агентов

Справочник обеспечивает:

- соответствие латинского имени 1С и русского имени Б24;
- единое отображаемое имя;
- привязку к команде;
- исключение дублей при группировке.

Сопоставление должно выполняться по явным алиасам. Нечёткое сравнение ФИО опасно из-за однофамильцев и разного наличия отчества.

## 11. Проверенные связи с исходниками

- На листе заказов найдено 886 уникальных счетов.
- 747 счетов присутствуют в `1C 14.07.xlsx`.
- 1 709 из 1 891 строк листа заказов имеют счёт, найденный в 1С.
- Из 148 уникальных CRM ID листа заказов 114 встречаются в 1С.
- В листе кейсов 479 ID второго блока совпадают с `Б24 NEW.xlsx`.

## 12. Ограничения автоматизации

1. Нельзя использовать pivot-кэш как долговременный источник данных.
2. Обновление существующих сводных может сократить историю до 1 891 заказов и 1 076 кейсов.
3. Внешние Excel-ссылки необходимо заменить локальными версионируемыми справочниками.
4. Нельзя напрямую складывать строки 1С и Б24: это разные представления одной деятельности и разная гранулярность.
5. Для финансового факта предпочтителен источник 1С; Б24 нужен для воронки, атрибутов сделки и оперативных показателей.
6. Ставка `1,22` действует для правил 2026 года. Для исторических периодов ставка должна определяться по дате и бизнес-схеме.
7. Пустое значение нельзя автоматически приравнивать к нулю: пустое означает отсутствие данных, ноль — известное нулевое значение.
