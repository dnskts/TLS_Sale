# Дашборд продаж РС ТЛС (PHP)

Офлайн-дашборд продаж по выгрузкам **1С** и **Битрикс24**.  
Работает в **одной папке на PHP** (подходит для размещения на сервере Битрикс24). Python не нужен.

## Как устроен проект (для джуна)

| Что хотите поменять | Какой файл открыть |
|---------------------|--------------------|
| Главная страница | `index.php` |
| Чтение настроек / агентов | `lib/settings.php` |
| Хранение данных (SQLite/JSON) | `lib/storage.php` |
| Парсинг Excel 1С | `lib/parse_1c.php` |
| Парсинг Excel Битрикс | `lib/parse_bitrix.php`, `lib/bitrix_export.php` |
| Авто-детект файлов в input/ | `lib/input_detect.php` |
| Сборка единой таблицы продаж | `lib/build_unified.php` |
| Фильтры | `lib/filters.php` |
| KPI и группировки | `lib/metrics.php` |
| Пересборка данных | `api/pipeline.php` или `php bin/pipeline.php` |
| Вкладка Обзор | `api/overview.php` + `assets/js/tab_overview.js` |
| Воронки | `api/funnel_*.php` + `assets/js/tab_funnel_*.js` |
| Настройки | `api/settings.php` + `assets/js/tab_settings.js` |
| Проверка сервера | `install/check.php` |
| Анализ скорости (прод) | `install/bench.php?token=…` |

Правило: **1 крупная фича = 1 файл** (или пара api + js). В файлах есть русские комментарии простым языком.

## Быстрый старт

1. Положите выгрузки в `input/` (имя файла **не важно**, тип определяется по структуре):
   - **1С** — xlsx, ~44 колонки, шапка с «Дата операции»
   - **Битрикс** — CRM export xlsx, лист «Отчет по сделкам» (~76 колонок)
2. Откройте в браузере `install/check.php` — убедитесь, что всё зелёное.
3. Пересоберите данные:
   ```bash
   php bin/pipeline.php
   ```
   или нажмите «Обновить данные» в интерфейсе.
4. Откройте `index.php` (через веб-сервер Apache/Nginx или локально):
   ```bash
   php -S 127.0.0.1:8080
   ```
   Затем http://127.0.0.1:8080/

## Бизнес-правила (не ломать)

1. 1С и Битрикс — независимые продажи (без дедупа между системами).
2. Прибыль = `profit_ex_vat`.
3. В продажах Битрикс только `deal_result == «Успех»`.
4. Дата 1С: `date_operation`; Битрикс export: `deal_created_at` (fallback для продаж; `client_paid_at` в export нет).
5. Битрикс KPI: `sales_amount` = «Всего к оплате Клиентом», `profit_ex_vat` = Комиссия + Сервисный сбор.
6. Маппинг агентов — только из `settings.json`, точное совпадение имён.
7. Воронка Битрикс — по **всем** сделкам.

## Хранилище

Автовыбор:

1. SQLite (`data/dashboard.db`), если доступен PDO SQLite
2. Иначе JSON в `data/tables/`

## Размещение на Битрикс24

**Требования:** PHP **7.4+**, расширения **json**, **mbstring**, **zip** (обязательны).  
**pdo_sqlite** — желательно (быстрее на больших данных), но не обязательно: без него используется JSON в `data/tables/`.

Скопируйте всю папку проекта в доступный каталог сайта.  
Откройте `install/check.php` — обязательные пункты должны быть **OK**.  
Убедитесь, что `data/` и `input/` доступны на запись.  
Папки `data/` и `input/` закрыты от прямого скачивания через `.htaccess` (Apache).

**Диагностика скорости:** `install/bench.php?token=XXXXXXXXXXXXXXXX` — замеры типичных API-сценариев. Token = первые 16 символов `settings_auth_token()` (тот же доступ, что у настроек admin). Без token страница вернёт 403.
